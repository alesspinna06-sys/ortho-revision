# Ortho Révision — contexte pour Claude

Logiciel de révision pour Shanel, étudiante en orthophonie. On y importe des cours (PowerPoint, Word, Excel, PDF, photos par QR code), et Gemini génère la fiche (avec schémas), les flashcards en répétition espacée, les QCM et les cas cliniques.

- **Machine cible** : Mac Intel sous **macOS Monterey 12.7.6** (ancien). Garder l'app légère : mode `.lite`, animations sur transform/opacity uniquement, une seule génération IA à la fois.
- **Build** : `npm run dist:mac` (et `npm run dist:win`). Nom produit **`Ortho Revision` sans accent** : un accent dans le chemin du .app faisait planter Electron (`EXC_BREAKPOINT`). Ce correctif n'a pas encore été confirmé sur sa machine.
- **Données** : `appData/Ortho Révision` (fixé dans `main.cjs`, identique avec `npm start` et l'app installée). Clés localStorage : `ortho-settings`, `ortho-gemini-key`, `ortho-activity`.
- **Node 22 LTS** obligatoire sur son Mac (une version plus récente provoque l'erreur `libc++`). Travailler depuis `~/Documents`, pas depuis une clé USB.
- **Fonctions propres à Ortho** : `src/lib/ai-ortho.js` (patient simulé, extraction des tests de bilan), vues `PatientView`, `TestsView`, `PhoneticsView` (`src/data/phonetique.js` : 100 mots en API, variantes admises), `components/Report.jsx`, schémas à trous (`domain.features.diagramQuiz = true`).

## Logiciel jumeau
**CAPES SES Révision** (`../capes-ses`) est une copie adaptée de ce projet, pour le CAPES de SES sous Windows. Fichiers qui diffèrent de façon permanente : `db.js` (stores `works` et `authors` en plus), `ai.js`, `App.jsx` (menu), `SettingsView`, `Dashboard`, `settings.jsx`, `srs.js`, `mobilePage.cjs`, `main.cjs` (dossier de données), `bridge.js` (clé localStorage), `domain.js`, `global.css` (palette). Tous les autres fichiers sont communs : une correction faite ici doit y être reportée, en remplaçant seulement « cas cliniques » par « études de documents » et l'icône `stetho` par `chart`.

## Pile technique

## Règles de travail (économie de tokens)
- Ne pas relire des fichiers entiers : `grep -n` ciblé, puis `sed -n a,bp`. Ce fichier tient lieu de vue d'ensemble.
- Modifier par ancres exactes (une seule occurrence vérifiée) plutôt que réécrire un fichier.
- Les deux logiciels partagent la plupart des fichiers (voir « Logiciel jumeau ») : toute correction commune doit être appliquée aux deux.
- Le texte propre à la discipline va dans `src/lib/domain.js` et dans les fichiers `ai-*.js`, jamais en dur dans les composants communs.
- Sécurité : tout SVG produit par l'IA passe par `sanitizeSvg` et s'affiche dans une `<img>` (jamais en innerHTML). Le Markdown est échappé avant d'être mis en forme.
- Aucune donnée inventée dans les prompts ni dans l'interface : l'IA doit signaler ce qui est « hors du cours », et les actualités ou chiffres sont toujours montrés avec leurs sources.
- Interface en français, tutoiement.

## Tests
`npm start` pour essayer, `npm run build` pour vérifier la compilation. L'IA se teste en simulant les réponses de Gemini : on reconnaît chaque requête aux propriétés de son `responseSchema` (summary, cards, questions…) ou à une phrase de son prompt.

## Pièges connus
- Gemini : une réponse JSON tronquée (`MAX_TOKENS`) donne une erreur explicite. Si la fiche échoue avec les images, elle est refaite sans elles. La recherche Google ne se combine pas avec `responseSchema` : on demande du texte libre et on parse le JSON. La recherche peut être indisponible selon le compte, un repli est prévu.
- `xlsx` est installé depuis cdn.sheetjs.com ; en cas d'échec, remplacer par `"xlsx": "^0.18.5"`.
- Le banc de test (esbuild + Playwright depuis `/opt/npm-tools`) embarque **React 19**, l'application **React 18**. `HtmlBlock` (Markdown.jsx) mémorise chaque bloc de texte : sans lui, React 19 réécrit le texte à chaque rendu et efface la sélection.
- Wikimédia Commons et l'API d'images de Gemini ne sont pas joignables depuis le bac à sable de Claude : leur code n'a été testé qu'avec des réponses simulées.
- Windows : l'installeur n'est pas signé, Smart App Control le bloque sans message.
